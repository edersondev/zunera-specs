## Ready-to-run protocol

Use a seeded account with multiple notification types, including a latest actionable item, a read item that still requires action, and a resolved item. Present each participant with the same starting screen outside Notifications. Do not describe where the center is or what the badges mean.

1. Ask the participant to find the newest item requiring action and open its source context. Record elapsed seconds from instruction to arrival at the correct source. SC-001 passes for a participant only if they find the center, identify the latest actionable item, and reach the correct context within 60 seconds without help.
2. Return to the center. Show one read-but-unresolved item and one resolved item without opening either source. Ask which still needs action and why. SC-007 passes for a participant only if they correctly identify both states without help.
3. Record an anonymous participant code, completion time, SC-001 pass/fail, SC-007 pass/fail, and any concise observation. Do not collect financial details or names.
