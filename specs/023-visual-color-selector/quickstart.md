# Quickstart: Visual Color Selector

1. On matching branches, complete backend allowed-value and contract tests. Run the three focused feature suites and Pint in the live backend container.
2. Add frontend palette tokens, shared utility and picker, then integrate the three fields. Run focused Vitest, lint, and build.
3. Run isolated Playwright journeys for account, category, and card selection in dark mode. Check 320px viewport, 200% zoom, keyboard flow, and existing colors.
