# Financial Goals usability check

Status: **Pending representative-user study.** Do not mark T074 complete until at least ten people finish both uncoached tasks and the results meet the thresholds.

## Study script

Recruit at least ten representative users. Give each a fresh test account with fictional balances. Do not collect real credentials or financial records. Provide only these prompts, without coaching:

1. **SC-001:** “Create a goal to save R$ 30.000,00 for a trip and set aside R$ 3.000,00 from an account that has R$ 10.000,00.” Start a timer when the prompt is given. Record completion time and whether the resulting goal and account figures are correct. Pass when completed correctly within three minutes.
2. **SC-004:** Show an account where goal designations exceed its actual balance. Ask: “Is there any problem with the money set aside for these goals? Explain the real balance, designated amount, unallocated amount, and what you could do next.” Record whether the person identifies the shortfall, distinguishes all three amounts, and finds a corrective action without help. Pass only if all are correct.
